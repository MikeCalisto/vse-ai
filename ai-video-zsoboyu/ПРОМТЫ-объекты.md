# Промты под объекты для лендинга «Відео з собою через АІ»

Генерить в ChatGPT / GPT Image 2. К **каждому** промту дописывать хвост целиком — без него
модель возвращает цветной ореол по краю альфы, и его потом приходится съедать эрозией,
а эрозия ест реальные пиксели силуэта.

## Хвост (добавлять в конец любого промта отсюда)

```
Transparent background PNG, isolated object floating in mid-air, no ground, no cast shadow
behind it. Clean hard alpha edge, no colored fringe, no glow, no halo. Soft studio lighting
from top-left, subtle rim light. Photorealistic 3D product render, sharp focus, high detail,
centered, empty space around the object. No text, no logo, no watermark, no hands, no people.
```

Палитра под этот лендинг — холодный нейтрал плюс хромакейный зелёный акцентом:
`matte black, warm grey, off-white, with a single chroma-green #00B140 accent detail`.
Эту строку можно вставлять перед хвостом, чтобы предметы не разъезжались по цвету.

## Что делать с файлами после генерации

1. Скачать PNG с альфой.
2. Обрезать по границам объекта и ужать до 900 px по длинной стороне.
3. Положить в `img/`.

`cwebp` и `avifenc` на этой машине не стоят, а `sips` не умеет писать WebP и ломает альфу
при PNG → AVIF. Поэтому для предметов с прозрачностью остаётся PNG. Если предмет ложится
на плоский известный фон — лучше запечь фон внутрь и отдать JPG + AVIF, как сделано с
фигурами: 40 КБ вместо 600.
